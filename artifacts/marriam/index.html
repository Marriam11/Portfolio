05
My core work

Building the system GenUI composes from

GenUI is only as good as the components it can reach for and the rules that govern them. Before AI could compose interfaces, it needed a design system that balanced flexibility with consistency, and a large part of the work wasn’t designing components but teaching GenUI when and how to use them.

What I did
Built the entire design system from scratch: atoms, tokens, form and GenUI-specific components. I authored the component spec system (use-when / avoid-when / examples) fed into each GenUI loop as system prompts: the foundation for how GenUI selected and composed UI.
1 · Build the system
Atoms → tokens → form components → rich components → data-viz components
2 · Define variability
Spec each component for the range of contexts GenUI will invent
3 · Author criteria
Use-when / avoid-when examples injected as system prompts
4 · Test & refine
See what GenUI reaches for, fill the gaps, rewrite until right
06
Theme system

Designing the rules for colour and image, not the output

As a host answers the interview, GenUI generates a themed invite, with no palette and no background image drawn in advance. My job was to design the rules that make every generated result feel intentional.

What I did
Designed the colour system and wrote the grading logic and prompt that governs how GenUI selects event-appropriate palettes. Separately defined the image-generation guardrails: mood, composition, positioning, exclusions, so every background feels intentional and brand-safe regardless of event type.
The colour palette system

I designed a four-role colour system. The prompt I authored tells the AI how to select a palette using that grading system as the constraint. A children’s birthday and a corporate dinner will never share a palette, but both will always be internally coherent.

Surgical Robotic Arm

AI-driven robotic assistance for real-time surgical tool detection & delivery

An AI-powered 6-DOF surgical robotic arm designed to assist surgeons by detecting and delivering surgical instruments in a simulated operating environment.

The system integrates computer vision using YOLO for real-time surgical tool detection with a robotic arm control system and a mobile-based voice command interface. Designed as a low-cost academic healthcare robotics prototype, it focuses on reducing manual effort and improving tool-handling efficiency in surgical workflows.

Final Year Project

01
The Challenge

Assisting operating rooms with AI & Robotics

In operating environments, manual instrument searching and handling add friction to time-sensitive workflows. This project created an integrated healthcare robotics prototype combining real-time computer vision, voice command control, and 6-DOF robotic movement to automate instrument detection and delivery in a simulated operating setup.

02
Key Highlights

System capabilities & Features

A low-cost academic healthcare robotics prototype tested across tool detection, voice commands, robotic movement, and full system integration.

Key Innovations
6-DOF
Robotic arm motion control designed for precise multi-axis surgical instrument pick, placement, and delivery.
YOLO
Real-time surgical instrument detection using YOLO object recognition powered by Raspberry Pi camera visual input.
Voice
Mobile-based voice command control enabling hands-free operation to request specific surgical tools dynamically.

Core Development Pillars

Hands-Free Mobile Control
Developed a mobile application with integrated voice command recognition for seamless, hands-free surgeon interaction.
Integrated System Testing
End-to-end integration testing uniting AI detection, mobile voice signals, and 6-DOF robotic kinematics in a simulated OR setup.
03
Phase 1 · Computer Vision

Surgical tool detection using YOLO

We implemented YOLO object detection on visual feeds from a Raspberry Pi camera to identify surgical tools in real-time, providing coordinate data for automated robotic pickup.

04

Voice commands & 6-DOF Movement

The mobile application processes voice triggers from surgical personnel, sending real-time operational commands to the 6-DOF robotic arm to deliver the requested surgical instrument safely and accurately.
